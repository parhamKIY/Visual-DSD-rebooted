MODEL PROGRAM
Parameter links
Edit system definitions, model nodes and parameter links in the source. Simulation and state exploration run one selected system. Fitting jointly uses the observed systems within each node, then passes posterior summaries along parameter links in dependency order. All fitted nodes are preserved in the result.

            

            

            

              

              

              
              

              
Select a species and time to inspect its marginal distribution. Heatmaps show copy number against time; bars show the selected sample. Result JSON and saved projects preserve the joint state probabilities, including correlations between species. This is numerical CME integration, not a sampled SSA histogram.

            

            

              

              

              
              
Move the time slider to inspect a frame. Hover over a cell for its exact value. In 1D, the heatmap averages adjacent samples when needed for display; the line shows the exact selected spatial profile. Explicit requested times use linear interpolation between integration output frames. Grid CSV contains every cell at every output time. Simulation and Data views show grid means; duplicated periodic endpoints are excluded.

            

            

              

              

              
Outgoing transitions

              
Complete reachable CTMC graph for the selected run, limited to 1000 states. Transition rates use the model's time unit; they are not probabilities. Absorbing states have no outgoing state changes. Shortest paths minimize the number of transitions. This view does not perform temporal-logic model checking. Export result JSON preserves all transition rates.

Each file belongs to one resolved run of the selected model system. SBML, ODE MATLAB and ODE LaTeX describe deterministic concentration equations; choose Oslo or Sundials. Download MATLAB files with their original names so the entry function matches the file.

              

              

              
              

            

            

              
PARAMETER SYNTHESIS

              

              

              
Dispersion displays the sampled instability band; CSV and project files retain the full sampled wave-number range. Jacobian arrows run from the influencing species to the affected species; orange is positive and teal is negative. Phase colors indicate the nearest displayed equilibrium at the final simulation time. Final distance is reported; proximity does not prove convergence or map an entire basin of attraction.

PARAMETER INFERENCE

              

              

              
              

              
              
Solid traces show pooled chains; dashed grey traces show chains excluded by the likelihood bound. Marginal densities, joint draws and intervals use only pooled chains. Split R-hat is the classical unranked statistic, unavailable for one chain, fewer than four retained draws per chain, or zero within-chain variance. It is not an automatic convergence verdict. Observation circles and maximum-likelihood curves are in Simulation.
