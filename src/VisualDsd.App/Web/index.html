Outgoing transitions

              
Complete reachable CTMC graph for the selected run, limited to 1000 states. Transition rates use the model's time unit; they are not probabilities. Absorbing states have no outgoing state changes. Shortest paths minimize the number of transitions. This view does not perform temporal-logic model checking. Export result JSON preserves all transition rates.
