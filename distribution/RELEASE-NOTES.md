Student workspace and portable classroom packages.

- Start with a guided lesson, import a DSD/CRN model, or reopen a saved project.
- Follow Check → Simulate → Review → Download, with progress derived from current completed results.
- Switch between Student and Full workspace without changing model settings.
- English by default, with optional Persian for the student journey and learning guides.
- Windows x64 and Linux x64 packages include the runtime, two first-run guides, example models, build metadata and SHA-256 checksums.

Download the ZIP for your operating system and extract it. On Windows, open VisualDsd.exe. On Linux, run `chmod +x VisualDsd` and then `./VisualDsd`. Read START-HERE.en.md or START-HERE.fa.md in the extracted folder.

This release adds a guided interface to the existing scientific engine. Dedicated Seesaw import and automatic truth tables are planned for the next stage. Classmate usability evaluation is still pending; local tests and the two-platform verification workflow cover the implemented paths.
