Logic circuit experiments, from Seesaw output to a measured truth table.

- Import actual Seesaw-generated Visual DSD source, including old syntax, without rewriting it.
- Map 1–4 logical inputs and 1–4 outputs to molecular structures, with optional dual rails, explicit units, ON/OFF concentrations and expected Boolean functions.
- Run all input combinations sequentially (up to 16), with bounded deterministic simulations, explicit cancellation and reconnection to already admitted jobs.
- Compare expected and observed outputs at a chosen time. Intermediate or invalid dual-rail signals remain unknown; execution errors and timeouts are separate.
- Inspect per-case curves and save source, mappings, readout rules, engine version, job identifiers and trajectories in a portable project. Export a truth-table CSV.
- Try the bundled three-level circuit, generated by the official Seesaw Compiler and verified across all eight input combinations.
- Keep the English interface or switch the student guides and experiment workspace to Persian.

Download and extract the ZIP for your operating system. On Windows, open VisualDsd.exe. On Linux, run `chmod +x VisualDsd` and then `./VisualDsd`. Read START-HERE.en.md or START-HERE.fa.md in the extracted folder.

Truth-table runs are deterministic, homogeneous experiments with one source simulation and no sweeps or scheduled inputs. Thresholds are model-specific. This feature does not compile arbitrary Boolean formulas into DNA, infer molecular mappings, or establish wet-lab correctness. Classmate usability testing is deferred until the full course project is complete.
