Complete the seven-stage coursework workspace with systems-biology lessons and a portable exercise collection.

- **Course exercises:** eleven guided activities connecting strand displacement, the Seesaw logic assignment, feedback/Adleman, sequence transformations, pairwise alignment, BLAST interpretation, multiple alignment, trees and systems biology. Every activity includes its goal, run path and acceptance questions.
- **Systems biology lab:** conserved conversion, promoter switching with mRNA/protein, and open/closed negative autoregulation. Run deterministic Oslo and 2–12 separate seeded SSA trajectories per condition. Inspect individual runs, sampled ensemble means and sample SD, endpoint mean/SD/CV/Fano, unavailable runs and conservation errors.
- **Reproducible work:** retain original requests, model sources, engine version, seeds, sample times, execution states and your own notes. Save/reopen a lab file, include the lab in a project, or export CSV, SVG, printable HTML and the complete experiment ZIP. Resume unfinished jobs explicitly; ambiguous admissions are never automatically retried.
- **Portable teaching pack:** English/Persian workbooks and authored FASTA, alignment, Newick and CRN inputs are included under `course/` in both platform ZIPs, and downloadable from inside the app.
- **Sequence tools since the previous classroom release:** DNA/RNA/protein records, FASTA/GenBank, transformations and translation, global/local affine alignment with matrix/traceback, BLAST table interpretation, optional NCBI retrieval, multiple alignment/conservation, strict Newick and UPGMA/NJ trees. Native MUSCLE 5 is an optional separately configured tool, never an installation requirement.
- **Validation:** analytic conversion and independently specified SciPy ODE references, actual seeded replays and conservation checks, project compatibility, bilingual UI, and standalone platform checks. These are software checks; they are not wet-lab validation or classmate usability evaluation.

Extract the entire ZIP. On Windows open `VisualDsd.exe`; on Linux run `chmod +x VisualDsd` then `./VisualDsd`. Start with **Course exercises** and read `START-HERE.en.md` or `START-HERE.fa.md`.

Core activities work offline. NCBI retrieval and online reference documents need internet. The rates and bundled datasets are illustrative. A sample-SD band is not a confidence interval; a finite-time endpoint is not evidence of stationarity. SSA `scale=1` is a numerical copy-population mapping, not a calibrated physical volume. The original engine may record its final SSA sample infinitesimally before the requested end; timestamps are retained unchanged. Intermediate curves interpolate/hold retained output samples, not every reaction event. RNA-seq/NGS pipelines, proteomics and structure prediction remain outside this package. Classmate evaluation is still pending.
